# Customer Registration Form

A responsive Customer Registration Form created using HTML5 and CSS3.

## Features

- Semantic HTML5 form elements and input types
- Built-in client-side validation using `required`, `minlength`, `pattern`, and `type` attributes
- Submit and Reset buttons
- Responsive layout built with CSS Grid and Flexbox
- Gradients, transitions, rounded corners, borders, colours, and responsive media queries

## Run locally

Open `index.html` in any modern web browser.
